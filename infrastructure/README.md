# Environnement et infrastructure as code

Copier les configurations As Code pertinentes depuis `application/` ou écrire une définition étudiée, puis documenter : finalité, mode de validation, conditions d'exécution, secrets exclus et limites.

**Nuance à expliquer :** Docker et Docker Compose peuvent s'inscrire dans une démarche Infrastructure as Code (environnement applicatif décrit dans des fichiers versionnés), sans pour autant être des outils IaC au même titre que Terraform ou OpenTofu, qui provisionnent et gèrent des ressources d'infrastructure avec un fichier d'état. Ne pas publier de fichier d'état ou de secrets.
